#Pingu Hop!: 
Pingu Hop is a variation of the actual game "crossy road". The game takes the general rules of "crossy road" and adds interesting features and different themes. Pingu Hop adds an interactive "obstacle" feature that forces the player to go around/avoid obstacles to continue playing. 

#Play the game: 
https://sharon5u.github.io/crossy-road/

#Controls: 
Use arrow keys to hop forward, backward, left, and right. Player can also use WASD keys to do the same. There are two separate trackers for scoring: one for the number of lanes crosses and one for the number of coins collected. 

#AI Models Used:
In class, I used Kiro to build the 30min challenge. After class, I continued by using Claude to add different themes and more complex features. I used ChatGPT to create background music for each theme.
